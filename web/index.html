THE DUAL-ENGINE ARCHITECTURE

Engineered For Competitive Esports

Two autonomous, ultra-reliable engines working in tandem to eliminate manual recording and review friction forever.

ENGINE 1 • RECORDING

Zero-Latency Scrim Watcher

Directly monitors League's Gameflow and Live Client Data APIs. Captures your Discord call and player microphone with sample-accurate timestamping.

  • 1

    Sub-Millisecond Match Start

    Attaches instantly when the game launches. Detects live games vs. replays with process guard.

  • 2

    Discord Local IPC Live Mute Sync

    Connects via Windows named pipe. When you mute or deafen in Discord, silence bytes are injected to preserve timeline lock.

  • 3

    Nexus Auto-Finalization

    Nexus explodes -> saves compressed <GameID>.mp3 aligned precisely to 00:00:00 without clicking any buttons.

ENGINE 2 • REPLAY SYNCHRONIZATION

Frame-Accurate Replay Lock

Hooks into the League Replay Playback API (:2999/replay/playback) and synchronizes audio via VLC Media Player.

  • 1

    Instant .ROFL Detection

    Opening any match replay in League automatically locates the matching <GameID>.mp3 in your recordings.

  • 2

    Dynamic Variable Rate Sync (0.5x - 8x)

    Fast forward or rewind during review; VLC dynamically adjusts voice playback speed in microsecond intervals.

  • 3

    In-Game Observer Mute ('M' Hotkey)

    Press 'M' while watching in League to instantly silence voice comms to hear important in-game audio cues.

Install Dependencies via Windows Package Manager

League Voice Recorder uses FFmpeg for audio sample alignment and 64-bit VLC for synchronized replay seeking.

PowerShell (Run as Administrator or standard user) 
# 1. Install FFmpeg (Audio conversion & offset alignment)
winget install -e --id Gyan.FFmpeg

# 2. Install VLC Media Player 64-bit (Replay playback engine)
winget install -e --id VideoLAN.VLC

Enable League of Legends Replay API

By default, League's local Replay API is turned off. You only need to add one line to your config file once:

Default Path: C:\Riot Games\League of Legends\Config\game.cfg
game.cfg configuration 
[General]
EnableReplayApi=1

Note: If [General] is already present in your game.cfg, simply add EnableReplayApi=1 right under it.

Discord Local IPC & Safe One-Time Authorization

On your very first run, Discord will display an official authorization popup:

"StreamKit Overlay wants to access your Discord account: Access your voice settings."

Simply click Authorize. The token is securely stored in config.json on your computer. Discord will remember your authorization and will never ask you again. Subsequent launches authenticate in <50ms.

Run Directly from Python Source via uv

Compatible with Python 3.12+ and 3.14. Uses the blazing-fast uv package manager.

PowerShell 
# 1. Clone the repository
git clone https://github.com/betterix/league-voice-recorder.git
cd league-voice-recorder

# 2. Sync dependencies
uv sync --dev

# 3. Launch the desktop GUI
uv run main.py

# 4. Run automated test suite (70 unit tests)
uv run pytest
SYSTEM ARCHITECTURE

Non-Invasive, Safe & Auditable

Designed from day one to operate safely alongside Riot Vanguard and Discord without triggering security flags.

100% Riot Vanguard Safe

Does not hook into game memory or modify game client binaries. Communicates only with official localhost HTTP APIs exposed by Riot.

Discord Native Named Pipe

Communicates directly over Windows local named pipe (\\.\pipe\discord-ipc-*) using the official StreamKit RPC overlay protocol.

Direct WASAPI Loopback

Uses Windows' built-in Audio Session API (WASAPI) directly. Avoids crashes caused by virtual cables and audio routing software.
